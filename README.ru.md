Строка состояния для [Command Code](https://commandcode.ai) (`cmdc`): модель, полоса контекста
с градиентом, доля попаданий в кэш, стоимость сессии, скорость вывода, расход субагентов, имя
сессии и состояние git — всё в строке под полем ввода.

```text
deepseek-v4.1-flash │ max │ █░░░░░░░░░░░ 32k (3.2%) │ cache 99% │ $0.013 │ 42 tok/s │ sub 16k │ Simple Reply │ main ↑1 │ +1 ~2 ?1 │ my-project
```

В Command Code нет внешнего хука `statusLine`, как в Claude Code: `cmd.ui.setStatus()` (API модов) —
единственный способ нарисовать постоянную строку под полем ввода, и этот мод использует именно его.

## Установка

```bash
cmd mods add holtwood/cmdc-statusline -g     # область пользователя (без -g — область проекта)
cmd mods list                                # мод должен появиться в списке
```

Можно и просто положить файл, без пакетного менеджера:

```bash
mkdir -p ~/.commandcode/mods
curl -o ~/.commandcode/mods/statusline.ts \
  https://raw.githubusercontent.com/holtwood/cmdc-statusline/main/index.ts
```

> В Windows бинарник называется `cmdc` (`cmd` открывает оболочку Windows) — используйте `cmdc mods add …`, `cmdc mods list` и т. д.

Попробовать без установки: `cmd --mod ./index.ts`. Моды загружаются один раз на процесс — после
правок нужен `/reload` или новая сессия. Шага сборки нет: Command Code компилирует TypeScript
при загрузке.

## Сегменты

| Сегмент | Значение |
|---|---|
| `deepseek-v4.1-flash` | Текущая модель, ровно как сообщил запрос (`raw-model=true` сохраняет префикс провайдера) |
| `max` | Уровень рассуждений последнего запроса |
| `█░░░ 32k (3.2%)` | Контекст последнего запроса: полоса с градиентом (зелёный→жёлтый→красный по ячейкам), токены, доля окна |
| `cache 99%` | Доля попаданий в кэш промпта (чтения кэша ÷ вход) |
| `$0.013` | Стоимость сессии: история при возобновлении + новое в этом процессе |
| `42 tok/s` | Скорость вывода последнего запроса (по настенным часам, включает ожидание первого токена) |
| `sub 16k` | Токены, израсходованные субагентами (инструмент `agent`) за сессию |
| `Simple Reply` | Имя сессии (сохраняется после `/reload` и возобновления) |
| `main ↑1` | Ветка git с ahead/behind |
| `+1 ~2 ?1` | в индексе · изменено · не отслеживается (`clean`, если чисто) |
| `my-project` | Имя текущего каталога |

## Настройка

Настройки хранятся в JSON; командная строка может переопределить их на один запуск.

```
~/.commandcode/statusline.json          область пользователя
<проект>/.commandcode/statusline.json   область проекта (приоритетнее)
--mod-option <name>=<value>             разовое переопределение
```

```json
{
	"bar-width": 12,
	"cache": true,
	"cost": true,
	"speed": true,
	"sub": true,
	"cwd": true,
	"refresh": 10
}
```

| Ключ | По умолчанию | Примечание |
|---|---|---|
| `model`, `effort`, `context` | `true` | модель / рассуждения / контекст последнего запроса |
| `bar`, `bar-width`, `percent` | `true`, `12`, `true` | полоса, ширина в ячейках, процент |
| `cache` | `true` | доля попаданий в кэш |
| `cost` | `true` | стоимость сессии |
| `speed` | `true` | скорость вывода |
| `sub` | `true` | токены субагентов |
| `name` | `true` | имя сессии (обрезается до 24 символов) |
| `git` | `true` | ветка + счётчики изменений |
| `cwd` | `true` | имя каталога |
| `raw-model` | `false` | сохранять префикс провайдера |
| `ascii` | `false` | принудительный ASCII-рендеринг |
| `refresh` | `10` | секунды между перечитываниями git (0 — таймер выключен) |

**О приоритете:** Command Code стирает **значения** `--mod-option` из argv, который видит мод.
Поэтому флаг считается явным переопределением только если его значение **отличается от встроенного
по умолчанию**. Явная передача значения по умолчанию (`--mod-option cwd=true`) не побеждает файл
настроек.

## Отрисовка

- `COLORTERM=truecolor|24bit` → 24-битная градиентная полоса; иначе приближение 256 цветами;
  `ascii=true` или `TERM=dumb` → `#`/`-`; `NO_COLOR` оставляет блочные символы, убирая цвет.
- **Узкий терминал — без обрезки:** сегменты отбрасываются по приоритету
  (`cwd` → скорость → effort → субагенты → кэш → имя сессии → стоимость → изменения, затем контекст
  сжимается с полосы → токены+% → токены, последней уходит ветка) и строка сразу перерисовывается
  при изменении размера. Модель не отбрасывается никогда.

## Откуда берутся числа

| Значение | Источник | Достоверность |
|---|---|---|
| модель / effort / контекст / кэш | события `model_request_start` / `model_request_end` | точно |
| стоимость сессии | `costUsd` из `<sessionId>.jsonl` при возобновлении + `usage` каждого запроса по таблице цен | часть при возобновлении — собственное число продукта; новая часть воспроизводит его расчёт (сверено запись за записью) |
| токены субагентов | событие `subagent_stop` | токены точно; расход субагентов **не** входит в стоимость (продукт его тоже не сохраняет) |
| имя сессии | событие `session_titled` + `<sessionId>.meta.json` при старте | по мере возможности — формат файла недокументирован, чтение обёрнуто в `try` |
| ветка / изменения | `git status --porcelain=v1 -b` через `cmd.exec` | точно, кэш 5 с |

Таблицы окна контекста и цен **генерируются** из каталога моделей, поставляемого с CLI, а не
пишутся вручную:

```bash
python3 scripts/gen-model-tables.py           # перегенерировать после обновления CLI
python3 scripts/gen-model-tables.py --check   # упадёт, если таблицы разошлись (это делает CI)
```

Отсутствующая модель деградирует аккуратно: нет окна — нет полосы и процента; нет цены — нет стоимости.

## Разработка

```bash
node test/statusline.test.mjs     # 136 проверок, без зависимостей и сборки
python3 scripts/gen-model-tables.py --check
```

Тесты импортируют `index.ts` напрямую: Node 22.18+/24 удаляет типы, поэтому инструментарий не нужен.
Проверить другую копию: `STATUSLINE_MOD=/path/to/statusline.ts`.

## Известные ограничения

- **Нет сегмента кредитов и квот.** Другие моды читают API Command Code ради остатка кредитов и окон
  5 часов/неделя; этот намеренно локальный (без сети и без `auth.json`).
- Стоимость новых запросов считается по встроенной таблице цен, а не перечитывается из транскрипта,
  поэтому при изменении цен нужно перезапустить `scripts/gen-model-tables.py` (и «семя» возобновления,
  и расчёт по запросу сверены с числами продукта).
- Имя сессии и восстановление стоимости читают `~/.commandcode/projects/**` — недокументированное
  расположение. Всё обёрнуто так, что при изменении раскладки просто исчезает сегмент, а не падает сессия.
